# C++ Test Coverage

This repository contains C++ exercises focused on improving test coverage, testability, and confidence when modifying existing code.

The repository is based on my study of unit testing and refactoring techniques in C++, with an emphasis on writing tests that document expected behavior and reduce the risk of regressions.

## Topics

- Unit testing
- Arrange, Act, Assert
- GoogleTest
- Mocking with Moq
- Test coverage
- Refactoring for testability
- Regression testing
- Dependency isolation
- Behavior verification

Goal

The goal of this repository is to strengthen my ability to safely modify existing C++ systems by building a reliable test suite around important application behavior.

Each exercise focuses on a specific testing or refactoring concept and includes both the implementation and the corresponding tests.
